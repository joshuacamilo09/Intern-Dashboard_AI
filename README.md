## Internal Analytics Platform for SMEs  
**Tech Stack:** Typescript | React | Postgresql

- Designed and developed a scalable **full-stack analytics platform** tailored for small and medium-sized enterprises (SMEs), enabling data-driven decision-making through an intuitive business intelligence dashboard.

- Engineered a **real-time KPI monitoring system**, delivering actionable insights such as:
  - Best-selling products  
  - Most active clients  
  - Revenue and performance trends  
  The system was optimized to ensure high responsiveness and accuracy across dynamic datasets.

- Implemented a **predictive analytics module** leveraging AI/ML models to forecast demand patterns, empowering businesses to anticipate market needs and significantly reduce manual reporting and analysis efforts.

- Architected a **fully normalized PostgreSQL database schema**, designed to efficiently handle complex aggregation queries and large data volumes while maintaining **sub-200ms response times under load**.

- Developed robust backend services using **Spring Boot**, following best practices such as:
  - Layered architecture (Controller, Service, Repository)  
  - DTO-based data exposure  
  - Validation and global exception handling  
  - Clean and maintainable API design (RESTful principles)

- Ensured system reliability and scalability through performance-oriented design decisions, including query optimization, indexing strategies, and efficient data access patterns.

- Built with a strong focus on **code quality, maintainability, and extensibility**, making the platform suitable for real-world production environments and future feature expansion.
